# AI-original sprites

This folder is the first version of the cat sprites, generated with Claude (AI)
from my descriptions of each animation, before any of my hand edits.

- `make_cat.py` — the AI-written script that drew every frame (64x64, white background)
- `frames/` — its 27 output frames
- `preview/` — GIFs and a contact sheet of those frames

My final, hand-edited frames are in `assets/frames/`. See `docs/CHANGES.md` for
what I changed.
